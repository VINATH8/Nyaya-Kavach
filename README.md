# 🛡️ Nyaya Kavach

**Nyaya Kavach** is a web-based citizen grievance platform designed to make complaint registration safer, faster, and more accessible. It enables users to report incidents through an intuitive interface while promoting transparency and easier communication between citizens and authorities.

## 🌐 Live Demo

🔗 https://nyaya-kavach-xzt1.vercel.app/

---

## 📖 About

Nyaya Kavach is developed to simplify the complaint registration process through a user-friendly digital platform. The project focuses on improving accessibility and encouraging reporting by providing dedicated portals for different stakeholders.

The platform consists of:

- 👤 **Citizen Portal** – Register and track complaints.
- 👮 **Police Portal** – View and manage registered complaints.
- 🤝 **NGO Portal** – Support victims and monitor complaint progress.
